
# SaludDocs

Aplicación móvil de gestión documental para funcionarios del área de Salud de la Corporación Municipal de Quilpué.

## Objetivo

Desarrollar un prototipo Android que permita a los funcionarios cargar, consultar y revisar documentos laborales de manera centralizada y segura.

## Tecnologías

- Android Studio
- Kotlin
- Jetpack Compose
- Arquitectura MVVM
- Firebase (integración planificada)
- Room (integración planificada)

## Funcionalidades del MVP

- Inicio y cierre de sesión.
- Carga de documentos PDF e imágenes.
- Consulta y búsqueda de documentos.
- Visualización del estado de revisión.
- Aprobación o rechazo por usuarios autorizados.
- Control de acceso según roles.
- Registro básico de acciones.

## Organización del código

- model: modelos de datos.
- ui/screens: pantallas.
- ui/components: componentes reutilizables.
- viewmodel: lógica de presentación.
- navigation: navegación.

## Seguridad

Proyecto académico desarrollado con datos ficticios. No se utilizarán documentos ni credenciales reales de funcionarios.
